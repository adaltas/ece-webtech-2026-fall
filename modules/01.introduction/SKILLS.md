# Skills

No book is used nor required. Reliable information is gathered from wikis, GitHub, source codes and various blogs.

The course assumes the following fundamentals. For each topic, a "you should be able to" line to self-assess, and short, free, hands-on resources to patch the gaps.

## Terminal

You should be able to: navigate directories, create/move/delete files, search a word across files with `grep`, and read a `man` page.

- [The Missing Semester: the shell](https://missing.csail.mit.edu/2020/course-shell/), one lecture with exercises _by MIT_
- [GameShell](https://github.com/phyver/GameShell), learn by playing

## Git source control

You should be able to: clone, stage, commit, create and merge a branch, resolve a merge conflict, and push.

- [Learn Git Branching](https://learngitbranching.js.org/), interactive game, do at least the intro sequence
- [Git Book](https://git-scm.com/book/en/v2) (chapters 1-3) and [Git tutorial](https://git-scm.com/docs/gittutorial), written documentation _by Git_
- [Git Cheat Sheet](https://www.git-tower.com/blog/git-cheat-sheet/), cheat sheet

## The web

You should be able to: retell the page-load sequence (DNS → TCP/TLS → request → response → render), resolve a domain with `dig`, and watch it happen in the browser.

- [How the web works](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Web_standards/How_the_web_works), article _by MDN_
- [Network Monitor](https://firefox-source-docs.mozilla.org/devtools-user/network_monitor/): open it on any site and identify the status codes, headers and timing phases

## HTML/CSS

You should be able to: structure a page with semantic tags and lay it out with flexbox.

- [Learn web development](https://developer.mozilla.org/en-US/docs/Learn_web_development), structured curriculum _by MDN_
- [Flexbox Froggy](https://flexboxfroggy.com/), learn flexbox by playing

## JavaScript

You should be able to: write functions (including arrow functions), manipulate arrays and objects, and use `map`/`filter`.

- [The Modern JavaScript Tutorial](https://javascript.info), the reference, part 1 chapters 2 to 5 cover the minimum
- [JavaScript first steps](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting), guided modules _by MDN_

## Markdown

You should be able to: write headings, lists, links, code blocks and tables without a cheat sheet.

- [Markdown Tutorial](https://www.markdowntutorial.com), interactive, 10 minutes
- [Markdown Guide](https://www.markdownguide.org/cheat-sheet/), cheat sheet to bookmark
